# Clippboard - Phase 1 (Steps 1-2)

Workspace shell with a custom dropdown (CustomSelect) and a custom drag-and-drop uploader (CustomDropzone).

## Run it on your computer
1. Install Node.js (version 18 or newer) from https://nodejs.org
2. Open a terminal in this folder
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Put it online (free)
Upload this folder to GitHub, then import the repository at https://vercel.com. Vercel detects Next.js and deploys it with no settings.
